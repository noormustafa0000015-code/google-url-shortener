
# Google Short

A beginner-friendly Google URL shortener web application.

## Current version

Stage 2 - Frontend Structure and Design

## Technologies

- HTML5
- CSS3
- JavaScript

## Project structure

google-url-shortener/
- index.html
- css/style.css
- js/app.js
- README.md

## Current features

- Responsive homepage
- Google URL input
- HTTPS validation
- Supported Google domain checking
- Success and error messages

## Upcoming features

- Unique short ID generation
- Cloudflare D1 database
- Cloudflare Workers backend
- Short URL redirects
- Custom domain support

## How to run

Open index.html in Google Chrome or Microsoft Edge.
